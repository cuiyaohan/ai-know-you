# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/), and this project adheres to
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-05

### Added
- Five-stage onboarding pipeline: intro → dig → (optional) assess → calibrate → assemble.
- Layered profile model (facts / preferences / boundaries) with local-first Markdown + frontmatter storage.
- Skeleton prompt rendering (SOUL / IDENTITY / USER / MEMORY / REDLINES) portable across agents.
- Privacy-first field redaction for sensitive categories.
- Revisit mechanism so the profile stays alive instead of one-shot.
- `run`, `sample`, `show`, `doctor` subcommands.
- Multilingual README (EN / 简体中文 / 繁體中文 / 日本語 / 한국어).
