## 中文描述词

**一句话简介**

> 让 Agent 从零开始「全方面懂你」的开源初始化向导 —— 一次对话，生成可移植的用户档案与 Agent 骨架提示词。

**完整描述**

> **ai-know-you** 是一套标准化、可复跑、可移植的 Agent onboarding 向导，对标 `create-react-app` 之于前端。它通过五阶段流水线（初识 → 深挖 → 可选测评 → 校准 → 装配），把「懂你」变成一项开箱即用的能力：生成分层用户档案（事实 / 偏好 / 边界）、按需推荐技能、并装配 SOUL / IDENTITY / USER / MEMORY / REDLINES 五份骨架提示词，适配主流 Agent 的记忆文件格式。数据本地优先、自动脱敏、支持复访增量更新。

## English Description

**One-liner**

> An open-source onboarding wizard that makes any Agent "fully understand you" from scratch — one conversation to a portable user profile and Agent skeleton prompts.

**Full description**

> **ai-know-you** is a standardized, repeatable, and portable Agent onboarding wizard — the `create-react-app` of "knowing the user." Through a five-stage pipeline (Intro → Dig → Optional Assessment → Calibration → Assembly), it turns "understanding you" into a ready-to-use capability: it generates a layered user profile (facts / preferences / boundaries), recommends skills on demand, and assembles the SOUL / IDENTITY / USER / MEMORY / REDLINES skeleton prompts compatible with mainstream Agent memory formats. Local-first, auto-redacted, with revisit-based incremental updates.
